# ASTRAL CLASH (v1 demo)

ブラウザで動く1人用デッキ構築カードゲームです。

## 起動

```bash
python3 -m http.server 4173
# http://localhost:4173
```

## 画面

- `index.html`: トップ画面（カードゲームボタン）
- `game.html`: デッキ構築 + CPU対戦

## v1で実装した要素

- デッキ30枚構築、同名3枚制限
- カード検索、コスト・タイプフィルタ
- localStorage保存
- CPU対戦（ターン制、コスト増加、ドロー、盤面上限、守護判定）
- ユニット / スペル / アミュレット
- 覚醒システム（先攻5T/後攻4T、2回まで、+2/+2 + 即時攻撃）
- カードプール60枚以上（ユニット・スペル・アミュレット）

## v1 と v2 の差分（計画）

| 項目 | v1 | v2 |
|---|---|---|
| カードプール | 60+ 共通プール | 100+ / クラス別 |
| CPU | ルールベース簡易AI | リーサル探索付きAI |
| 進行 | 基本ターン制 | マリガン/疲労/詳細履歴 |
| 演出 | 最小限UI | 攻撃・覚醒・生成演出 |
| 収集 | なし | パック開封・レアリティ |
| デッキ保存 | 1つ | 複数デッキ |
